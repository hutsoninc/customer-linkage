| 2026-06-26 | Tooling | Address classification and remediation scripts — built a pipeline that compares contact physical and mailing address fields against a ZIP code dataset and classifies each address into one of five states: **Complete** (zip valid, city/state match, county and country present), **Enrichable** (zip valid, city/state match, county or country missing), **Conflicted** (zip valid but city or state disagrees with dataset), **Geocodeable** (zip absent/unrecognized but street + ≥2 of zip/city/state are present), or **Insufficient** (too few fields to validate or geocode).
